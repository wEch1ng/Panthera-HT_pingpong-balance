# Panthera-HT V1.1.0 Follower

Contains the supplied Follower URDF (fixed fingers, enabled D405 camera) and only its referenced visual/collision meshes. Original `package://Panthera-HT_description_V1.1.0/...` paths are resolved within this folder by `sim.urdf_converter`.

Source: https://github.com/HighTorque-Robotics/Panthera-HT_SDK

Original package metadata and SDK license are preserved. `sim.build_model` applies the narrower gripper gap and deeper rigid paddle mount to the generated scene without modifying this URDF.
